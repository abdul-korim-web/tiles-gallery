## 📌 Project Overview

This is a **Tiles Selling E-Commerce Web Application** built using **Next.js** App Router

Users can:
- Browse premium tile collections
- View detailed product information
- Search tiles by name
- Explore featured products
- Manage profile
- Experience smooth animations & responsive design
---

## ✨ Features

- 🧱 Product listing (20+ tiles)
- 🖼️ High-quality product gallery
- 📄 Dynamic product details page
- ⚡ Server-side rendering (SSR)
- 🔄 ISR caching (revalidate support)
- 📱 Fully responsive UI (mobile + desktop)
- 🎨 Modern UI with animations
- 🔐 Auth-ready navbar design
- 🧭 Active route navigation highlight

## 🚀 How to Run This Project

```bash
# Clone repo
git clone https://github.com/abdul-korim-web/tiles-gallery

# Open folder
cd tiles-gallery

# Install dependencies
npm install

# Run project
npm run dev
```
## Open in browser:
```

http://localhost:3000
```
